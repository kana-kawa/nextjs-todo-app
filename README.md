# ToDoリスト（共有できるタスク管理）

タスクとカレンダーの予定を管理できる Web アプリです。
リンクを送るだけで、家族や友人と同じリストを一緒に編集できます。ログインは不要です。

**公開URL**: https://nextjs-todo-app-three-mu.vercel.app/todo

> Next.js とデータベースの練習として、個人で作ったものです。

## 主な機能

- **タスク**
  - タスクを追加し、完了・削除できる
  - 期日を付けられ、「今日やること」と「期日のあるタスク」に分けて表示する
- **カレンダー**
  - 月ごとのカレンダーで、日付を選んで予定を追加・削除できる
- **共有**
  - 「共有する」を押すと共有用のリンクができ、リンクを知っている人は誰でも同じリストを見て編集できる
  - 編集した内容は自動でサーバーに保存され、ほかの人の変更も定期的に読み込んで反映する
  - 共有をやめたいときは「共有を解除する」で、サーバーからリストを削除できる
- **データの保存**
  - 共有していないリストはブラウザ（localStorage）に保存する
  - 共有したリストはデータベース（PostgreSQL）に保存する

## しくみ

| 場面 | 処理 |
|---|---|
| 共有リンクを作る | API（`POST /api/share`）でデータベースに新しいリストを作り、ランダムなIDを発行する |
| 共有リストを開く | ページを表示するときに、サーバー側でデータベースからリストを読み込む |
| 編集する | 入力が落ち着いたタイミングで、API（`PUT /api/share/[id]`）からデータベースを更新する |
| 共有を解除する | API（`DELETE /api/share/[id]`）でデータベースからリストを削除する |

## 開発環境で動かす

Neon などの PostgreSQL の接続文字列を、`.env.local` に設定します。テーブルは初回アクセス時に自動で作られます。

```
DATABASE_URL=postgres://...
```

```bash
npm install
npm run dev      # http://localhost:3000/todo で起動
npm run lint     # ESLint
npm run build    # 本番用にビルド
```
